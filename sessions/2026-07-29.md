# 2026-07-29 作業ログ

## 概要

Blender 5.0 系（検証環境: 5.0.1）対応の調査と実装。`fix/update4.4` ブランチ（Blender 4.4 向けに組み込み FBX Exporter を再取り込みしたもの）をベースに、作業ブランチ `fix/update5.0` を作成して対応した。

## 調査結果

- 本アドオンは Blender 組み込み `io_scene_fbx` を `sket_unreal/fbx_export/` に丸ごと同梱してラップする構造。フォークの目的は、アクション選択出力を実現する独自パッチ（`SKET_TAG_EXPORT` によるフィルタ）を Exporter 本体に埋め込むため。
- `main` の同梱 Exporter は Blender 3.2 頃のもので、`calc_normals_split()` / `free_normals_split()` / `me.vertex_colors` など 4.0 で削除された API を使用しており 4.0+ でクラッシュする。
- `fix/update4.4` は Exporter を 4.4 版へ再取り込み済みで上記クラッシュは解消していたが、**独自パッチ（アクションフィルタ）の再適用が漏れており**、SELECT/NONE/分割出力が機能せず全アクションが出力される重大リグレッションがあった。

## 実施内容（ブランチ: `fix/update5.0`、ベース: `origin/fix/update4.4`）

1. **同梱 Exporter を 4.4 → 5.0 へ更新**
   - `fbx_export/export_fbx_bin.py`, `fbx_export/fbx_utils.py` を Blender 5.0.1 同梱版へ差し替え（他4ファイルは 5.0 と同一のため変更なし）。
   - 5.0 版に SKET 独自改変を再適用:
     - アクションフィルタ（`SKET_TAG_EXPORT`）を `fbx_animations` のアクションループ先頭へ再挿入（**リグレッション修正**）。
     - FBX Creator メタ文字列のバージョン取得を `from .. import bl_info`（親パッケージ `sket_unreal` の bl_info 参照）に変更。
2. **SKET 側の 5.0 非互換修正**
   - `sket_fbx_export_functions.py`: `action.fcurves` が 5.0（スロット付き Action）で廃止されたため、新旧両対応の `iter_action_fcurves()` ヘルパーを追加し `apply/revert_action_scale_x100` を書き換え。
3. **既存バグ修正**
   - `__init__.py`: `bl_info` を `version=(1,5,0)` / `blender=(5,0,0)` に更新、`unregsiter` タイポ修正。
   - `sket_delete_action.py`: 関数名 `unregsiter` → `unregister`。
   - `sket_fbx_export.py`: no_armature モードで `target_armature_name` が無条件上書きされるバグを修正（`if not no_armature_mode` でガード）。
